# Beecrowd 1037 - Intervalo



## Descrição



Este programa resolve o problema 1037 do Beecrowd.



## Tecnologias utilizadas



- Java

- NetBeans

- Maven



## Entrada



A entrada contém um valor de ponto flutuante.



## Saída



O programa apresenta em qual intervalo o valor se encontra:



**Intervalo \[0,25]**

**Intervalo (25,50]**

**Intervalo (50,75]**

**Intervalo (75,100]**



Caso o valor não pertença a nenhum intervalo, apresenta:



**Fora de intervalo**
